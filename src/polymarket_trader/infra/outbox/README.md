# outbox 目录说明

该目录存放可靠事件队列和异步持久化入口。Outbox 是交易动作和数据库落库之间的缓冲层，目的是让数据库抖动不阻塞交易链路。

## 职责

- 接收轻量结构化审计事件。
- 为关键事件生成幂等键。
- 在数据库失败时保留可重试事件。
- 将事件交给 Persistence Worker 异步落库。

## 事件分级

- 高优先级：订单创建、签名、提交、成交、取消、risk failure、resting BUY 异常。
- 低优先级：大体积 raw response、调试快照、指标快照、报表数据。

## 允许依赖

- `polymarket_trader.observability` 的审计事件模型。
- `polymarket_trader.infra.db` 仓储。
- 标准库队列、文件或当前采用的可靠存储实现。

## 禁止行为

- 不在交易主链路中同步写 PostgreSQL。
- 不无限增长队列。
- 不把未脱敏 raw response 放入高优先级事件。
- 不吞掉关键订单事件失败。

## 输入与输出

- `put` 类接口必须有容量和背压策略。
- 关键事件需要幂等键。
- 消费失败需要保留重试次数和最后错误。
- 数据库慢时，低优先级快照可以合并、降采样或延后，关键交易事件必须保留。
