## 维护

- 新增接口、配置项或人工操作入口时，同步改文档。
- 名称和源码保持一致。
- 不写密钥、私钥、未脱敏响应。
- 不保留一次性执行清单、改造计划、迁移过程记录或已经被当前代码取代的历史表述。
