# 体育扫尾策略验收与风控清单

本文档用于开发、回放、人工验收和上线前检查。任何自动下单能力启用前，都必须逐项确认。

## 1. 候选识别清单

候选必须满足：

- [ ] 比赛处于直播状态。
- [ ] 比赛名称、联赛、队伍或选手清晰。
- [ ] 当前比分可读。
- [ ] 当前阶段或剩余时间可读。
- [ ] 盘口类型属于白名单：`Totals`、`Moneyline`、`Spreads`。
- [ ] 盘口线和目标方向清晰。
- [ ] 候选原因可解释。
- [ ] 主要风险可解释。

候选必须拒绝：

- [ ] 未开赛比赛。
- [ ] 比赛状态暂停、延期、取消、争议或退赛。
- [ ] 比分、阶段或盘口含义不清楚。
- [ ] 盘口规则无法确认。
- [ ] 盘口类型不在白名单。

## 2. Totals 清单

通过条件：

- [ ] 当前总分已经超过 Over 盘口线，且目标方向为 Over。
- [ ] 或者当前总分与盘口线、剩余时间形成明显安全垫。
- [ ] 当前价格仍有折价。
- [ ] 可成交深度满足目标金额。

拒绝条件：

- [ ] 只依赖模糊判断认为 Under 不会再被打穿。
- [ ] 当前价格接近 100¢，预期收益不足。
- [ ] 比分存在争议或刚变化后尚未稳定。
- [ ] 盘口规则包含特殊取消、延期或重赛处理且无法确认。

## 3. Moneyline 清单

通过条件：

- [ ] 比赛进入末段。
- [ ] 领先优势明显。
- [ ] 领先方价格仍有折价。
- [ ] 加时、补时、犯规战术或退赛风险可接受。

拒绝条件：

- [ ] 小比分领先且剩余时间仍多。
- [ ] 存在明显加时或反转风险。
- [ ] 价格已经充分反映胜率。
- [ ] 规则或比赛阶段不清楚。

## 4. Spreads 清单

通过条件：

- [ ] 比赛进入末段。
- [ ] 当前领先差距相对让分线有足够安全垫。
- [ ] 最后阶段得分不容易改变让分结果。
- [ ] 价格和流动性满足交易要求。

拒绝条件：

- [ ] 比赛仍处于早中期。
- [ ] 垃圾时间得分可能改变让分结果。
- [ ] 安全垫不足。
- [ ] 盘口线或结算方向不清楚。

## 5. 价格与流动性清单

交易前必须确认：

- [ ] 买入价格低于策略上限。
- [ ] 预期收益覆盖交易成本。
- [ ] 预期收益覆盖滑点。
- [ ] 目标金额有足够卖盘深度。
- [ ] 价差没有异常扩大。
- [ ] 市场没有关闭或暂停交易。

拒绝条件：

- [ ] 买入后理论收益过薄。
- [ ] 实际成交均价会超过上限。
- [ ] 深度不足导致无法完成目标金额。
- [ ] 盘口价格剧烈波动且无法判断真实价格。

## 6. 风控清单

自动交易前必须确认：

- [ ] 单笔金额未超限。
- [ ] 单场比赛风险未超限。
- [ ] 单个联赛风险未超限。
- [ ] 单日风险未超限。
- [ ] 同一比赛多个盘口没有重复暴露不可控风险。
- [ ] 连续亏损暂停条件未触发。
- [ ] 当天亏损上限未触发。
- [ ] 当前策略执行权限允许本动作。

任何一项不满足，都必须拒绝交易并记录原因。

## 7. 执行权限清单

执行权限必须明确：

- [ ] `只记录`：只能进入日志和复盘。
- [ ] `只提醒`：只能展示机会，不得创建订单。
- [ ] `人工确认`：人工确认后仍必须经过风控。
- [ ] `自动执行`：满足全部检查后才允许下单。

禁止行为：

- [ ] 人工确认绕过风控。
- [ ] 管理入口直接调用交易客户端。
- [ ] 某个策略单独维护下单旁路。
- [ ] 因为候选“看起来确定”而跳过价格和流动性检查。

## 8. 退出清单

买入后必须持续检查：

- [ ] 价格是否达到目标卖出价。
- [ ] 比赛是否即将结束或已经结束。
- [ ] 比赛状态是否异常。
- [ ] 盘口是否关闭或流动性消失。
- [ ] 是否出现比分或状态冲突。
- [ ] 是否需要减仓、退出或转人工处理。

退出动作：

- [ ] 价格回归后提前卖出。
- [ ] 结果稳定且风险可控时等待结算。
- [ ] 状态异常时停止加仓。
- [ ] 风险扩大时优先保护本金。

## 9. 审计清单

每个候选必须记录：

- [ ] 比赛。
- [ ] 盘口。
- [ ] 盘口类型。
- [ ] 当前比分。
- [ ] 当前阶段。
- [ ] 盘口线。
- [ ] 候选方向。
- [ ] 当前价格。
- [ ] 候选原因。
- [ ] 通过或拒绝原因。

每笔交易必须记录：

- [ ] 买入时间。
- [ ] 买入价格。
- [ ] 买入数量。
- [ ] 执行权限。
- [ ] 退出时间。
- [ ] 退出价格或结算结果。
- [ ] 实际盈亏。
- [ ] 异常处理记录。

## 10. 上线前验收

上线前必须完成：

- [ ] 静态样例验证。
- [ ] 历史或模拟回放验证。
- [ ] 只记录模式观察。
- [ ] 只提醒模式观察。
- [ ] 人工确认模式闭环。
- [ ] 小额度自动执行验证。
- [ ] 异常状态演练。
- [ ] 当日亏损上限演练。

未完成以上验收时，不允许扩大自动执行额度。
